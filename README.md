# Word-counter

A growing collection of free, simple, and useful online tools designed to make everyday tasks easier.

## Available Tools

### Word Counter

A free online tool to count words, characters, sentences, paragraphs, and lines, with additional text analysis features.

## Features

- Free to use
- No account or registration required
- Simple and user-friendly interface
- Responsive design
- Privacy-conscious text processing

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Vision

Utility Hub aims to bring together useful tools for students, productivity, text processing, and everyday tasks in one accessible platform.

More tools will be added over time.
